# FocusFlow Landing Page

A static landing page built as part of The Odin Project Foundations course.  
The project focuses on mastering HTML structure and CSS layout using Flexbox.

## Live Demo: https://anik-hindu.github.io/odin-landing-page/

## 🛠️ Built With

- HTML5
- CSS3
- Flexbox

## 📚 What I Learned

- Structuring a complete webpage using HTML
- Using Flexbox for layout alignment and spacing
- Breaking down a design into reusable sections
- Managing spacing using margin and padding effectively

## Features

- Header with navigation links
- Hero section with call-to-action
- Information section with cards
- Footer layout
- Responsive layout
- Testimonial section
